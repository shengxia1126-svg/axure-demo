#拆單配置

匹配規則：


##獲取符合匹配金額的所有廣告


## 採用：**目標完成率權重（推薦）**


### 每個廣告維護四個值


target_volume    // 目標成交量（掛單數量）

done_volume      // 已成交量 （ 匹配中+已成交)


target_count     // 目標成交筆數  (掛單最大拆掉筆數)

done_count       // 已成交筆數    （ 匹配中+已成交筆數)


## 計算權重


### 第一步：完成率


```text

volume_rate = done_volume / target_volume


count_rate = done_count / target_count

```


### 第二步：公平分


fair_score = 1 - (volume_rate * 0.7 + count_rate * 0.3)


> 金額佔70%，筆數佔30%。（可設置參數跳調整）


限制：

fair_score < 0

則 = 0


## 最終權重

weight = fair_score + 0.01

加 0.01 是避免權重變成 0。


## 加權隨機


例如目前三個廣告：


| 廣告 | 成交量   | 目標量    | 成交筆數 | 目標筆數 |

| -- | ----- | ------ | ---- | ---- |

| A  | 20000 | 100000 | 20   | 100  |

| B  | 5000  | 10000  | 50   | 100  |

| C  | 900   | 1000   | 80   | 100  |


計算：


A

volume_rate = 0.2

count_rate = 0.2

fair_score=1-(0.2×0.7+0.2×0.3)=0.8


B


0.5

0.5

fair_score=0.5


C

0.9

0.8

fair_score=1-(0.9×0.7+0.8×0.3)=0.13


得到權重：


A = 0.80

抽中概率：
